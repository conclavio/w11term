# netwatch

> Inspect network activity, connections, and diagnostic results from the terminal.
> More information: <https://github.com/matthart1983/netwatch/blob/v1.0.0/README.md>.

- Start the compact dashboard for a small pane:

`netwatch --lite`

- Try the dashboard with a recorded example:

`netwatch --demo`

- Print a machine-readable diagnostic report:

`netwatch doctor --json`
