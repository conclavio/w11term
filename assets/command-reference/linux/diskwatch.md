# diskwatch

> Inspect disk activity, filesystem capacity, and busy paths in a terminal dashboard.
> More information: <https://github.com/matthart1983/diskwatch/blob/v0.7.2/docs/REFERENCE.md>.

- Open the compact dashboard in a small SSH pane:

`diskwatch --lite`

- Watch activity under a particular directory:

`diskwatch --watch "{{path/to/directory}}"`

- Print a diagnostic snapshot and exit:

`diskwatch --diag`
