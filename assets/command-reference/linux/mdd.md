# mdd

> View rendered Markdown with mddog in a terminal that supports Kitty graphics.
> More information: <https://github.com/qu8n/mddog/blob/v1.5.1/website/content/docs/usage.mdx>.

- Render a local Markdown file:

`mdd "{{path/to/file.md}}"`

- Pick a Markdown file from a directory:

`mdd "{{path/to/directory}}"`

- Read Markdown from standard input:

`mdd < "{{path/to/file.md}}"`
